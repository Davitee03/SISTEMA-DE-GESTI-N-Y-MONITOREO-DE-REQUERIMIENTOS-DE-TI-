# SISTEMA-DE-GESTI-N-Y-MONITOREO-DE-REQUERIMIENTOS-DE-TI-
Sistema web de gestión y monitoreo de requerimientos de TI para Rocanet, con clasificación automática de tareas mediante IA (NLP), control de acceso basado en roles (RBAC) y dashboard de indicadores KPI para optimizar la asignación y resolución de solicitudes.
